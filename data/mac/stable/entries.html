I2P 2.14.0 Release

I2P 2.14.0 is mostly bug fixes and hardening, with most of the work in the BitTorrent client (i2psnark). It includes bug fixes across several systems improving security and stability.

i2psnark: magnet links now use all of their trackers, torrent creation and rechecking use less memory, and the client checks disk space before adding torrents and closes files properly.

There are also a few security fixes, including a local downgrade that could bypass proxy authentication in i2ptunnel, an out-of-bounds read in garlic clove parsing, and a buffer overflow in NTCP.

Under the hood, the streaming layer has some synchronization fixes, and tunnels no longer process duplicate fragments.

For a detailed changelog, please see the local changelog.

As usual, we recommend that you update to this release. The best way to maintain security and help the network is to run the latest release.

Unfortunately we were unable to release a 2.0.0 OSX Easy-Install Bundle in December as promised. As the 2.1.0 release was accelerated by six weeks, we will not be releasing 2.0.0. We are now focused on the build and release for the 2.1.0 Bundle.

I2P Mac Bundle with Java 18.0.1 Security Update

A security vulnerability affecting the Java Runtime Environment used by I2P has been disclosed. Please update your Mac bundle to I2P 1.7.1 as soon as you can.
